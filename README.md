## Лабораторна 1. Основні бібліотеки та лінійні моделі

NumPy, pandas, PyTorch і Matplotlib; лінійна регресія на PyTorch (власний сценарій «години сну → продуктивність»), збереження моделі та Gradio-застосунок.

- `linear_models_lab.ipynb`: ноутбук з усіма вправами.
- `dataset.csv`: власні згенеровані дані; `model.pt`: натренована модель.
- `screenshots/`: скріншоти виконання (зокрема CPU/GPU).

## Лабораторна 2. Нейронні мережі для регресії

Повний цикл роботи з табличним датасетом **Medical Insurance Cost** (таргет `charges`): спліт до аналізу, EDA, пропуски й викиди, кодування й стандартизація, baseline на лінійній регресії, три архітектури нейромережі та чотири експерименти з гіперпараметрами (по одній зміні за раз), логування в TensorBoard, Gradio-застосунок для порівняння моделей.

- Найкраща модель: `nn_v3_lr_0.001` (Tanh, 64→32, Adam, lr = 0.001): test RMSE ≈ $4 919, R² ≈ 0.844 проти ≈ $6 121 і 0.758 у лінійної регресії.
- Контроль: лінійна модель із вручну доданими ознаками-взаємодіями `smoker × bmi` досягає R² ≈ 0.867, тобто основний виграш мережі це знайдена нелінійна взаємодія.
- `models/`: усі 8 варіантів (`.pt`); `runs/`: логи TensorBoard; `results.csv`: метрики на test.

Перегляд логів: `tensorboard --logdir lab2/runs`.

## Лабораторна 3. Токенізація та трансформери

Токенізатори BPE, WordPiece і Unigram на власному українському корпусі (українська Вікіпедія), mini-GPT з нуля у кількох варіантах (розмір словника, довжина контексту, глибина мережі), тур по `pipeline()` із українськими прикладами, порівняння готових моделей на задачі sentiment-analysis та творчий Gradio-застосунок «Радар відгуків».

- `transformers_demo.ipynb`: виконаний демо-ноутбук лекції 4.
- `transformers_task.ipynb`: завдання; запускається зверху донизу (Run All), для розділу 3 потрібен GPU (у Colab: *Середовище виконання → T4 GPU*).
- `models/minigpt_v*.pt`: чекпоінти кожного варіанта mini-GPT (разом із конфігурацією та токенізатором); `runs/`: логи TensorBoard.
- `results.csv`: порівняння варіантів mini-GPT (`val_loss`, `val_bpc`) і моделей з розділу 5; стовпець `part` розрізняє блоки.

Основні результати:

- **mini-GPT** (4.9 млн параметрів, 8000 ітерацій на T4, корпус: перші 12 000 статей української Вікіпедії): за порівнянною метрикою `val_bpc` (біт на символ) найкращі глибша мережа (8 шарів, 2.057) і довший контекст (128, 2.068), базовий має 2.130, а менший словник (5000) найгірший (2.240), хоча його сирий `val_loss` здається найменшим (4.55). У всіх варіантів `val_loss` ще падав на останній ітерації, тобто моделі недонавчені.
- **Токенізатори** (словник 500): char-level BPE найкоротший (1.68 символа/токен), Unigram єдиний тримає частотне слово цілим, WordPiece найгірший (1.52).
- **Sentiment-analysis** на 20 власних реченнях: `xlm-roberta (twitter)` accuracy 0.90, F1 0.91; `bert-multilingual (stars)` 0.75 / 0.71; `distilbert-multilingual` 0.60 / 0.33.
- Застосунок «Радар відгуків» (Gradio): тональність і тема кожного речення відгуку, підсумок за темами.

## Запуск

1. Відкрити потрібний ноутбук у [Google Colab](https://colab.research.google.com/) (File → Open notebook → GitHub).
2. Для лабораторних 2 і 3 увімкнути GPU (T4).
3. Виконати **Run All**. Залежності ноутбуки ставлять самі.
4. Артефакти (`models/`, `runs/`, `results.csv`) створюються поруч із ноутбуком.
